# MyPortfolio Mobile

Aplikasi Flutter dasar untuk Tutorial 08 PBP. Halaman utama menampilkan identitas pemilik portofolio dan kartu menu Experience, Education, serta Projects. Menekan kartu akan menampilkan SnackBar.

## Menjalankan

Pastikan Flutter SDK terpasang, lalu jalankan dari folder proyek:

```bash
flutter pub get
flutter devices
flutter run -d chrome
```

Untuk memeriksa kualitas kode:

```bash
flutter analyze
```
